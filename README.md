# 🚀 Septian Putra Rachman Hakim (iannnub) | Personal Portfolio

Welcome to the repository of my personal portfolio website! This project is a modern, high-performance, and fully responsive web application built to showcase my skills, projects, and professional journey as a Software Engineer and AI Enthusiast.

🌐 **Live Demo:** [porto-iannnub.vercel.app](https://porto-iannnub.vercel.app/)

---

## ✨ Features

- **🏎️ Blazing Fast Performance:** Built with Vite + React 18 for instant load times.
- **📱 Fully Responsive:** Beautiful UI/UX tailored for both desktop and mobile screens.
- **🏎️ Custom JDM Ignition Sequence:** Unique loading screen featuring a synthesizer and Web Audio API engine start with real JDM "Stutututu" turbo flutter sounds.
- **🕷️ Dynamic 3D Elements:** Framer Motion spring physics and interactive hovering animations to keep the user engaged.
- **🎨 Premium UI/UX:** Styled using Tailwind CSS with glassmorphism, dynamic gradients, and custom modern typography.
- **🔍 Professional SEO:** Fully loaded with Open Graph, Twitter Cards, Canonical links, and PWA mobile configurations for perfect social media sharing.

## 🛠️ Tech Stack

- **Frontend Framework:** React 18 + TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS v3
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** Vercel (Recommended)

## 💻 Local Development

Want to run this project locally? Follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/iannnub/iannnub-port.git
   cd iannnub-port
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

## 📂 Project Structure

- `public/`: Static assets including images, audio (`jdm-engine.mp3`), and SEO thumbnails (`og-image.jpg`).
- `src/components/`: Reusable UI components (Buttons, Cards, Navbars, Footers).
- `src/data/`: Centralized data files for profile info, projects, and certifications. Edit these files to easily update the website's content without touching the core logic!
- `src/sections/`: Major sections of the website (Hero, About, Projects, Experience, Contact).

---

## 🚀 Deployment (Vercel)

This project is highly optimized for deployment on Vercel:
1. Push this repository to your GitHub account.
2. Go to [Vercel](https://vercel.com/), login with GitHub.
3. Click **Add New Project**, import your repository, and click **Deploy**. Vercel will handle the rest!
